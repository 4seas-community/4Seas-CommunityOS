# 4Seas-CommunityOS

Organize the Place, Event, and People for Community.

运营于物理世界的在地社区操作系统:管理自运营建筑中的场地(Place),驱动活动(Event)的完整生命周期,服务成员(People)的注册、验证、预订与积分;通过 Luma / Social Layer / Telegram Bot / Agent API 对内降噪、对外分发。
